### 計算與觸發語義

- 只計棋盤上的不同 characterId；同名、星級和備戰席不加人數。玩家與敵人獨立計算，開戰快照鎖定，死亡不取消階級；準備操作才更新 UI。
- 數值順序為基礎 → 星級（HP／普攻取整）→ 羈絆固定值 → 同層百分比相加 → 自身增益／控制狀態 → 最終有效值。戰鬥副本保存 modifier，原始資料不變；初始化有 WeakSet 一次性保護。
- 普攻、技能、持續傷害與額外觸發分成 attack／skill／dot／trigger。閃電和射手追擊不再次發出普攻事件；燃燒不由燃燒或追擊再次觸發。吸血只使用實扣 HP，治療不會再造成傷害。
- 法師 4 人首次傷害技能的 +15% 與 +30% 同層相加，該次合計 +45%；只影響傷害。星辰強化在星級後乘 1.15，適用傷害／治療／護盾；治療師是出量增幅，自然是受量增幅。
- Burning／Slow／Freeze 管理來源、強度、持續與剩餘時間，採單狀態最強值＋刷新規則。燃燒每秒一跳共四跳；來源死亡仍可由既有燃燒造成傷害，但不再發起攻擊或吸血復活。冰凍 1 秒、同目標 5 秒冷卻，傷害技能冰凍亦共用冷卻。
- 既有自身攻速／防禦增益保留 P1 欄位與固定時鐘；護盾獨立累加並先吸收，不列為治療。所有狀態、技能和回復都走 50ms 模擬步進，暫停與速度倍率不改規則。
- 開戰順序：鎖定羈絆 → 原始上場角色固定／百分比加成與護盾 → 戰術家能量與冷卻 → 召喚師靈體。靈體不繼承羈絆，之後的全隊技能可治療／保護靈體。
- 每隊同時最多 2 個靈體，12 秒消散；2 人靈體 HP 320／攻擊 42，4 人強化為 HP 480／攻擊 63。角色技能可補召，但不能突破存活上限；技能召喚強度最高 2.0，無空格直接略過。
- 靈體參與清場勝負，但不計正式角色存活數、超時 HP 比例或戰敗扣血的存活角色數；不計上場上限、羈絆，不施放技能。
- 黃金收益由戰鬥快照寫入結果，僅 Run 結算把它加入 income.gold；自由戰鬥不修改經濟。回合階段與 settledThrough 保護一次性發獎。

## 基線與調整

1. [trait-balance-baseline.json](trait-balance-baseline.json) 保留第一輪同預算比較。自然隊用了過多古樹填充、星辰隊用了四名相同能量支援，造成組成偏差（自然 5%、星辰 92.5%）。先改用有傷害與支援的完整隊伍，仍維持同費用／星級／人數／等級；這是測試陣容改進，不能視為同陣容係數調整的效果。
2. [trait-balance-before-tuning.json](trait-balance-before-tuning.json) 保存修正陣容後、數值調整前的 220 場。之後只調整新增角色：燼影遊俠 HP 680→760、攻擊 72→82、技能傷害 190→240；霜冠衛士 HP 970→1100、攻擊 43→52、防禦 42→50；冰露祭司治療 210→250。舊十二名數值與全部羈絆需求係數保持原值。
3. 使用相同新陣容重跑（最終版本亦包含刺客受阻時攻擊可達前排的尋路修正，因此差異不能全部歸因於數值調整），霜月勝率 20%→40%；烈焰 17.5%→15%，並未因提高單體數值而改善，已如實保留。未為追求漂亮勝率更改燃燒係數或刪掉不利對局。
4. 此樣本最高勝率 90%，最低 15%，沒有全勝／全敗隊伍。星辰、雷霆偏強，烈焰、自然仍偏弱；結果僅涵蓋這些一星 Lv.8 固定隊伍，不代表所有站位、商店經濟或二三星環境都已平衡。

## 效能與穩定性

- 本次 Node 核心執行 115664 個固定步進，220 場耗時約 3.99 秒（環境會影響時間）。最大單場單位紀錄 42（含已死亡靈體），最大保留事件 169；每次陣容測試檢查有限數值與狀態數上限。
- 額外十回合召喚／控制壓力測試確保新回合 Battle 置空、時間歸零、持有角色不殘留靈體；每場單位紀錄少於 100、事件少於 800。這是生命週期與有界集合驗證，並非完整 heap snapshot 證明。
- 靜態棋格與座標烘焙到 RenderTexture；動態文字使用物件池，只有視覺狀態改變才重繪，高／低畫質最多處理最近 48／16 個特效事件。羈絆只在準備操作改變或開戰時計算。
- [browser-frame-baseline.json](browser-frame-baseline.json) 與 [browser-frame-sample.json](browser-frame-sample.json) 是相同召喚／霜月對第十關、4×、各 90 幀的瀏覽器採樣，包含戰鬥及結算停留畫面。最佳化前高畫質中位數約 133ms，之後約 50ms；低畫質 P95 約 133ms 降至約 50ms。
- 採樣是 Linux headless Chromium 軟體 WebGL，不能宣稱 Windows／實體 GPU 均達 60 FPS；本次採樣中位數約 20～30 FPS，仍有硬體與渲染限制。關閉動畫不影響核心結果，傷害／治療統計保留完整數值。
